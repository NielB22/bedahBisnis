# bedahBisnis 🏪

DIY pipeline untuk membuat video animasi isometrik "bedah bisnis" — exploded-view ekonomi sebuah bisnis dalam format short video.

> Dibuat untuk belajar dan portofolio. Terinspirasi dari kitabedah.id.

## Apa ini?
Pipeline otomatis dari **topik bisnis** → **animasi 3D isometrik** → **narasi** → **video pendek** siap upload.

Contoh pertama: **Kopi Susu** — bedah biaya per gelas, margin, dan break-even point.

## Status
🚧 Fase 0 — Fondasi (setup repo & riset)

## Tech Stack
- Three.js (mesin gambar isometrik)
- Gemini API (TTS & riset)
- Remotion / ffmpeg (render video)
- Node.js
